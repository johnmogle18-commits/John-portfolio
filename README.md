# John Benedict M — Official Portfolio Website

An athlete and sports scientist portfolio website created for **John Benedict M** — former I-League professional footballer (Mumbai FC, Pune FC), AIFF D-License Certified Coach, and elite Strength & Conditioning Specialist at Sree Kanteerava Stadium's Centre of Sports and Science (CSS).

---

## 🚀 How to Run Locally

To start the development server locally, run:

```bash
npm run dev
```

The application will start immediately at:
`http://localhost:5173/`

To build the optimized production bundle:
```bash
npm run build
```
